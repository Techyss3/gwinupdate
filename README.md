# Guek Player Desktop — Windows sürümleri

Bu repo yalnızca **Guek Player Desktop** Windows kurulum dosyalarını ve otomatik güncelleme
meta verisini (`latest.yml`) barındırır. Kaynak kod ayrı (private) bir repodadır.

## İndirme

Son sürüm: <https://github.com/Techyss3/gwinupdate/releases/latest>

`Guek Player Desktop-<sürüm>-Setup.exe` dosyasını indirip çalıştırın. Kurulu uygulama yeni sürümleri
açılışta kendisi indirip kurar; elle güncelleme gerekmez.

## Sürüm listesi

Tüm sürümler: <https://github.com/Techyss3/gwinupdate/releases>

- `vX.Y.Z` etiketli release'ler uygulama sürümleridir.
- `mpv-runtime` etiketli release, uygulamanın kullandığı `mpv.exe` çalışma zamanını tutar (build altyapısı içindir, kullanıcıların indirmesine gerek yoktur).
